# Бот остатков ПФЦ WB (@pfc_tlt_bot)

Python 3.10+, библиотеки в requirements.txt. Запуск: `python bot.py`.
Это фоновый воркер (long polling): HTTP-порт не нужен.

## Переменные окружения
| Переменная | Значение |
|---|---|
| BOT_TOKEN | токен от @BotFather |
| ADMIN_USERNAMES | ник владельца без @ |
| PFC_PHONE | номер для входа в my-pfc.wb.ru, 7XXXXXXXXXX |
| STORAGE_ID | 398912 |
| STATE_FILE | путь к файлу входа на постоянном диске, например /data/state.json |

Если у платформы есть постоянный диск (volume), подключите его и укажите STATE_FILE на него —
тогда вход в кабинет не будет теряться при перезапуске. Без диска после каждого
передеплоя нужно заново сделать /login в боте.

## Первый запуск
1. Напишите боту /start, затем /login.
2. Пришлите код из SMS. Готово — селлеры могут присылать баркоды.
